## clima_board 
### הרצת הפרויקט
#### הורדת הספריות

להריץ את פקודת `pip install -r requirements.txt` בתיקית הפרויקט הראשי
להריץ את פקודת  `npm install` בתיקיית front

### הרצת הפרויקט

הרצת פקודה `py app/main.py` בתיקיה הראשית של הפרויקט או  `py main.py` בתיקית app
הרצת פקודה `npm run dev` בתיקית front
